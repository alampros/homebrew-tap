# alampros/homebrew-tap

Personal Homebrew tap for distributing macOS apps.

## Usage

```bash
brew tap alampros/tap
brew install --cask onair-companion
```

## Available Casks

| Cask | Description |
|---|---|
| `onair-companion` | Monitor Microsoft Teams meeting status and forward to homebridge-onair |

## Updating

```bash
brew upgrade --cask onair-companion
```
